# Policy Folder – Ypifany

This folder includes machine-readable policies that support and enforce the privacy practices described at Ypifany.org.

---

## 🔒 Minimum Age Requirement (Child Access Policy)

- **File**: `child_access_policy.yaml`
- **Purpose**: Prevent collection of personal data from users under 13
- **Enforces**: Age restriction per our Privacy Policy
- **Use Case**: Blocks form submissions if user age < 13 and displays a message

---

These files are designed for use with future automation, audit logs, and policy enforcement through CI/CD pipelines or web hooks.
